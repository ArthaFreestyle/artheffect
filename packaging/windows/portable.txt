Artheffect portable mode

While this file sits next to artheffect.exe, Artheffect keeps its settings, keyboard shortcuts,
crash-recovery files, logs and plug-ins in the ArtheffectData folder beside it instead of
%APPDATA%\Artheffect. Copy the whole folder to move Artheffect with its settings.

The disk cache, media cache and conformed audio still go to %LOCALAPPDATA%\Artheffect unless
you choose other folders in Edit > Preferences > Disk.

Delete this file to use the normal per-user settings folder (%APPDATA%\Artheffect) instead.
If ArtheffectData can't be written (for example on a read-only drive), Artheffect logs a
warning and uses %APPDATA%\Artheffect instead.
